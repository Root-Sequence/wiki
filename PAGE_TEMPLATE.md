# Wiki Entry Template

Use only the fields that help. The wiki should stay lightweight enough to actually maintain.

```yaml

slug: example
type: concept | phrase | motif | project | seed
status: seed | working | established | retired | composted
provenance: origin-unverified
provenance_confidence: low
first_known: unknown
projects: []
aliases: []
related: []
canonical: null
```

# Example

## Short definition

One or two sentences answering: **what does this mean here?**

## Why it matters

What problem does the term solve, distinction does it preserve, or relationship does it make visible?

## Ecosystem use

- **Project A:** how it appears there.
- **Project B:** how that treatment differs.

## Provenance

What is currently known about the wording and its history? Link evidence where available. Use "first known" rather than "first" unless authorship has actually been established.

## Evolution

```text
YYYY-MM — first known appearance
YYYY-MM — renamed / expanded / challenged
```

## Open questions

What remains unresolved, contested, or worth testing?
