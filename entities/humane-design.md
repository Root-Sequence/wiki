# Human(e) Design

A Root Sequence translation methodology for turning grounded observations about human experience, care, harm, access, agency, uncertainty, maintenance, and power into concrete design questions and testable decisions.

The parenthetical `(e)` preserves the distinction between designing *for humans* and designing *humanely*. Understanding human behavior can support care and agency, but it can also support manipulation, extraction, compliance, or exclusion.

## Ecosystem role

```text
Being Human(e) notices.
Human(e) Design translates.
Implementation tests.
Human(e) Infrastructure makes selected capacities durable.
Real use feeds new observations back into the loop.
```

Human(e) Design is currently a cross-project methodology, not a separate repository or implementation authority.

## Naming note

The exact stabilized label **Human(e) Design** was formalized on 2026-09-07. Earlier ecosystem work already used overlapping language around humane design, accessibility, legibility, human-scale systems, and architecting humane infrastructure. The Wiki should preserve those earlier strands without retroactively pretending the exact name was already canonical.
