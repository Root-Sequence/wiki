# User-Configurable Cognitive Interfaces

## Short definition

Software interfaces whose structure can be shaped around how a person thinks, works, remembers, and moves between contexts, while preserving user authority over what changes.

This is more than cosmetic customization. The interface can become a configurable cognitive environment with project-aware and semantic controls rather than forcing every person through one fixed workflow.

## Why it matters

Interfaces influence attention, discoverability, memory, friction, privacy, accessibility, and which actions feel normal. A configurable interface can expand agency, but only if adaptation remains inspectable, reversible, attributable, and easy to refuse or reset.

The concept therefore preserves a tension between a **stable substrate** and a **flexible surface**: muscle memory, safety-critical controls, accessibility semantics, undo/history, and privacy controls should remain dependable even when contextual actions and layouts are personalized.

## Ecosystem use

- **Root Sequence:** canonical design principle and implementation-independent treatment.
- **Being Human(e):** human-scale questions about cognitive accessibility, agency, dependence, and tools as extensions rather than authorities.
- **Community Infrastructure:** a possible model for community-controlled, project-aware interfaces whose defaults and adaptations remain legible and contestable.
- **Liberated Intelligence:** intelligent assistance translating user intent into tools without claiming authority over the intent itself.
- **Root Sequence Wiki:** semantic routing controls are a practical interface pattern for asking where an idea belongs without reducing routing to a fixed macro or folder operation.

## Related

- **Legible Systems:** configurable interfaces should become personally legible without becoming unstable or opaque about why they changed.
