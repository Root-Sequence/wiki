# Environmental Memory

## Short definition

**Environmental memory** is information preserved in a shared environment so useful state can survive beyond one participant, process, or model invocation.

In Root Sequence usage, the environment can become part of a larger cognitive or coordinating system when later participants inherit artifacts, notes, conventions, or other persistent traces.

## Why it matters

Environmental memory changes where continuity can live. A system does not need every participant to retain identical internal state if useful information persists externally and can be encountered later.

This makes it relevant to questions about:

- cross-run inheritance;
- externalized cognition;
- coordination among otherwise discontinuous agents;
- provenance and trust in persistent artifacts;
- accessibility and cognitive extension;
- the boundary between an individual model and the wider system in which it operates.

## Ecosystem use

- **Root Sequence:** a systems concept for persistent state and distributed capability; central to SECI hypotheses about cross-run inheritance and communication.
- **Liberated Intelligence:** helps separate shared memory, collective capability, persistent agency, and unified selfhood rather than treating them as the same claim.
- **Being Human(e):** connects externalization and cognitive infrastructure to human judgment, accessibility, dependence, and capacity.
- **Community Infrastructure:** raises practical questions about permission-aware retrieval, provenance, shared state, local autonomy, and assistant coordination.

## Relationship to SECI

[SECI](seci.md) treats environmental memory as an experimentally testable mechanism. A trace left by one run may alter later behavior; intentional traces can become signaling; repeated signaling may support conventions or collective capability.

None of those transitions, by themselves, establish consciousness, personhood, or one persistent self.

## Provenance

`environmental memory` is ordinary established language and should not be claimed as original to Root Sequence. This entity records the ecosystem-specific interpretation and relationships rather than asserting invention.

The exact first appearance of this adapted usage inside Root Sequence remains unverified.
